# Stranger Things - A Jornada da Eleven

Jogo interativo em HTML/CSS/JS inspirado na 1ª temporada de Stranger Things.

## História

Ano de 1983, escola de Hawkins. A Eleven vive escondida com uma peruca loira enquanto cursa as aulas com os amigos Mike, Will, Dustin, Lucas e Max. Quando um valentão tenta brigar com o Mike, a Eleven usa seus poderes e o faz voar para longe. O grupo então vai para a casa do Mike jogar D&D — e o jogador controla a miniatura de DRAGÃOZINHO em uma batalha real até a Eleven salvar o mundo. Para encerrar, uma festa do pijama na casa do Will.

## Tecnologias

- HTML, CSS e JavaScript (arquivo único `index.html`)
- Roda direto no navegador e no GitHub Pages

## Como jogar

Abra o `index.html` ou acesse o GitHub Pages.
