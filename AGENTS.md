# Agents

## Regras de versionamento

TODA alteração feita neste repositório DEVE ser commitada e enviada (push) ao GitHub imediatamente após a modificação.

### Fluxo obrigatório

1. Após qualquer edição de arquivo, executar:
   ```
   git add .
   git commit -m "descrição da alteração"
   git push
   ```

2. Nunca deixar alterações pendentes sem commit.

3. Mensagens de commit devem ser claras e descritivas em português.
